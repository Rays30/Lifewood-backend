# 🌿 Lifewood Internship Website

This project was developed during my internship at **Lifewood Data Technology**, as part of my practical training in **web development and Firebase integration**.  
The website showcases the company’s profile, open job positions, and contact details, with an integrated **admin dashboard** for managing job applications and contact messages.

---

## 🚀 Features

### 🌐 Website (Frontend)
- **Home Page** – Introduces Lifewood and its services with smooth animations.  
- **About Page** – Describes the company’s mission, culture, and values.  
- **Careers Page** – Lists open positions with an integrated **Job Application Form**.  
- **Contact Us Page** – Allows visitors to send messages directly to the admin.  
- **Responsive Design** – Works on desktop, tablet, and mobile devices.  
- **Scroll and Animation Effects** – Adds a modern and interactive feel.

### 🧑‍💻 Admin Dashboard (Backend)
- **Firebase Authentication** – Admin login protection.  
- **Job Applications Management** – View, filter, and delete submitted job applications.  
- **Contact Messages Management** – View, reply, or remove contact messages.  
- **Real-time Firebase Database** – Automatically updates when new submissions arrive.  
- **Clean and organized UI** for better workflow.
